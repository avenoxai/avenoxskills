# Hook & title pattern library

Theory beats design: people click videos they **want to watch**, not pretty
images. The thumbnail **opens a curiosity gap**; the title and the video close
it. Never put the same words on the thumbnail and the title — build across
them.

## Thumbnail text rules

- **2-4 words max.** More reads as a "PowerPoint cover" and consistently
  underperforms.
- White + **one accent** word; thick black outline; huge; bold block sans-serif.
- **Don't finish the thought.** If the hook feels slightly incomplete or
  uncomfortable, it's right.

## Hook angles (pick the sharpest for the video)

| Angle | Feel | Example |
|---|---|---|
| Contradictory curiosity | "wait, how?" | NOT STUPID · I DIDN'T EVEN READ IT |
| Negativity / risk | fear of loss or mistake | IT'S LYING TO YOU · BANNED |
| Cliffhanger question | must be resolved | WHY DOES IT FORGET? · WHICH ONE WON? · WORTH THE MONEY? |
| Tangible number / timeframe | concrete payoff | 3 HOURS → 20 MINUTES · $100 → $375 · 8 MODELS 1 TASK |
| Contrast / flip | before/after, ✓/✗ | NOT WHAT → WHY · NOT VIBE CODING · THE BORING ONE WON |
| Authority / how-to | insider certainty | WRITE THE PROMPT LIKE THIS · HOW I BUILT MY SYSTEM |
| Sensational promise | bold payoff | BUILT A GAME IN ONE PROMPT · WORKED FIRST TRY |
| Generosity / value | free gift | I'M GIVING AWAY MY SKILL |
| Comedy / relatability | local humor | a dated price reference, an in-joke |

Comedy travels worst across languages — it depends on shared reference. When
localizing, replace the joke rather than translating it.

## Title patterns (front-load the keyword)

Contradictory curiosity • tangible timeframe • insider authority • negativity •
weight of regret • personal victory • cliffhanger question • broad
relatability • buzzwords • sensational promise.

**Put the topic keyword or model name FIRST** in the title — the first one or
two words carry the most scan weight and the most search weight. The thumbnail
hook and the title should be *different words pointing at the same payoff*.

## Mapping a video → hooks (the routine)

1. Read the title and description. Find the single most surprising or valuable
   claim in the video.
2. Generate 2-3 **different** angles from the table above (e.g. one curiosity,
   one number, one contrast) so the user can A/B genuinely contrasting
   directions — not three variants of one idea.
3. Choose the logo(s) that name the tools actually in the video.
4. Pick an accent color by emotion: red = urgency/danger, green = success/money,
   blue = tech, purple = automation, gold = value, cold-blue = dystopia.

## A/B testing note (small channels)

YouTube's native Test & Compare (up to 3 covers, judged by watched-time share)
is free — turn it on. But at low impressions (~1-3K views) the results are
noisy and should not be treated as truth.

Better at small scale: ship the single strongest cover, watch first-24-48h CTR
in Analytics, and swap manually if it lands under ~4-6%. A/B becomes
statistically meaningful around 10K+ views per video.

## Series rule

No episode number or name on the cover — it kills parts 2 and up. Each part
gets its own context-specific hook, plus a different accent color and pose so
the covers don't look like copies.
